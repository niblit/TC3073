# Decision Log

| Date | Decision | Description | Justification |
| :--- | :--- | :--- | :--- |
| 2026-08-14 | Threat Model Formulation | Black-box, problem-space evasion attacks with zero model weight/gradient access, bounded by a strict perturbation budget, targeting phishing and Business Email Compromise (BEC) detectors. | Models realistic attackers targeting email security gateways who can only observe classification outcomes or confidence scores. |
| 2026-08-21 | Detector Zoo Scope | Train and evaluate an in-house, multi-tier detector zoo (linear baseline, deep character-level, and transformer models) rather than borrowing third-party pre-trained classifiers. | Guarantees architectural diversity (n-gram lexical, subword/character, contextual semantic) to empirically test attack transferability and inductive bias failure modes. |
| 2026-08-24 | Initial Dataset Selection | [`ealvaradob/phishing-dataset`](https://huggingface.co/datasets/ealvaradob/phishing-dataset) (`combined_full.json`). | Aggregated public corpus of Email, SMS, URL, and HTML phishing samples covering diverse communication vectors. |
| 2026-08-28 | 3-Layer Transformation Taxonomy | Formalized `Transformation` hierarchy separating perturbations into Content (`TargetedContentTransformation`), Structure (`StructureTransformation`), and Metadata (`MetadataTransformation`). | Grounded in problem-space adversarial ML principles (Cortellazzi et al., 2023) to decouple semantic paraphrasing from layout obfuscation and delivery header spoofing. |
| 2026-08-28 | Perturbation Budget Enforcer | Explicit `PerturbationBudget` class tracking consumed edits vs. `max_edits` (relative budget 0.0 to 1.0) with strict `BudgetExceededError` enforcement. | Guarantees adversarial transformations remain bounded, preventing unconstrained mutations from destroying realism. |
| 2026-09-11 | Dataset Curation & Reduction | Filtered full dataset (871k rows) down to ~77.7k textual email/SMS samples in `combined_reduced.json`. | The full dataset was heavily skewed toward raw URLs and short web artifacts; reduction produced a clean, balanced text corpus essential for training NLP detectors and evaluating semantic attacks. |
| 2026-09-11 | Reproducibility & Split Protocol | Stratified 80/20 train/test split with fixed random seeds (`split_random_state=42`, `model_random_state=42`). | Eliminates data leakage across evaluation phases and ensures deterministic benchmark reproducibility across all zoo models. |
| 2026-09-14 | Baseline Detector | TF-IDF Vectorizer (max 10,000 features) + Logistic Regression pipeline saved to `detector_zoo/models/logistic_regression`. | Standard, fast, and interpretable n-gram bag-of-words baseline representing classical spam/phishing filters (Accuracy: 89.10%, F1: 86.56%). |
| 2026-09-21 | Adversarial Attack Algorithm: TextFooler | Adopted and implemented the TextFooler algorithm (Jin et al., 2019) with query-based word importance ranking and greedy replacement. | Upgrades heuristic stubs to a peer-reviewed, state-of-the-art black-box attack that strategically targets high-impact classification tokens. |
| 2026-09-22 | Word Embeddings: Counter-Fitted Vectors | Counter-fitted word vectors (`adversarial_examples/data/counter-fitted-vectors.txt`, Mrkšić et al., 2016) loaded via Gensim `KeyedVectors`. | Standard distributional embeddings (Word2Vec/GloVe) place antonyms and synonyms close together due to shared contexts; counter-fitting enforces linguistic constraints that pull true synonyms together and repel antonyms, preventing meaning corruption. |
| 2026-09-24 | Dual Intent-Preservation Constraints | Universal Sentence Encoder (USE v4) cosine similarity threshold ($\ge 0.84$) and spaCy (`en_core_web_sm`) POS-tag consistency filtering. | Prevents semantic drift and grammatical disfluency, ensuring generated adversarial messages remain coherent and persuasive to human victims. |
| 2026-09-24 | Hard Invariant Semantic Verification | Rule-based invariant validation in `verify_intent`: preservation of named entities, numerical values, and URLs/emails. | Phishing and BEC lures rely critically on intact monetary amounts, brand entities, and call-to-action links; mutating these invariants nullifies the attack's functional utility. |
| 2026-09-25 | Structural & Metadata Transformations | Implemented `HTMLCommentInjection` (DOM/comment noise at word boundaries) and `TimestampSpoofing` (Date header manipulation). | Extends attack surface beyond pure content/lexical mutations to evaluate detector sensitivity to non-semantic formatting and envelope heuristics. |
| 2026-09-27 | Char-CNN Detector | Character-level CNN in PyTorch with 1D convolutions (kernel sizes 3, 5, 7; 64 filters; 1024 char sequence length) saved to `detector_zoo/models/char_cnn`. | Evaluates model robustness against token-splitting, leetspeak, and character-level obfuscations without relying on whitespace tokenization (Accuracy: 94.84%, F1: 93.89%). |
| 2026-09-28 | Unified Detector Interface & Decoupled CLI Oracle | `BaseDetector` ABC (`fit`, `predict`, `predict_proba`, `save_model`, `load_model`) paired with a stdin/stdout CLI oracle (`predict.py`). | Enforces strict black-box isolation between the adversarial harness and detectors, preventing in-process state leakage and supporting arbitrary model backends. |
| 2026-09-29 | Transformer Detector | Fine-tuned DistilBERT (`distilbert-base-uncased`, max length 256, 3 epochs, AdamW lr=2e-5) saved to `detector_zoo/models/transformer`. | Represents state-of-the-art contextual semantic representations in production security gateways while balancing training and inference efficiency (Accuracy: 97.01%, F1: 96.43%). |
| 2026-10-06 | Reproducible Environment & Tooling | Nix Flakes (`flake.nix`) with `uv` virtual environment and pinned Python 3.12 packages across all submodules. | Guarantees identical execution environments across development and CI, avoiding dependency and binary conflicts across PyTorch, TensorFlow Hub, and Hugging Face. |
| 2026-10-11 | Degradation Curve Analysis Protocol | Automated budget sweep harness (`analysis/run_analysis.py`) sweeping perturbation budgets (1% to 100%) against target detectors. | Provides a standardized measurement protocol to quantify model brittleness, tracking accuracy drop, evasion rate, and confidence degradation across budgets. |
